# SAFEVIEW 제품 개요

SAFEVIEW는 도로변 주차 차량 등으로 시야가 제한되는 골목과 주차 환경에서 보행자 위험을 감지하는 Streamlit 기반 CCTV 모니터링 시스템이다. RTSP CCTV 또는 로컬 영상에서 YOLOv8로 사람과 차량을 인식하고, 사용자가 지정한 ROI 안에 보행자가 있으면서 이동 차량이 함께 감지되면 위험으로 판단한다. 위험 발생 시 화면·음향 경고를 제공하고 전후 영상, 이미지, CSV 로그를 저장해 다시 볼 수 있다.

## 현재 제공 기능

- 로컬 영상 업로드·재생 및 RTSP 카메라 프리셋 연결
- 사람, 자동차, 오토바이 탐지와 장시간 정지 차량 제외
- 영상 소스별 다각형 ROI 설정·저장·불러오기
- 저조도 프레임 자동 보정과 실시간 위험 시각화·경고음
- 위험 이미지와 전 5초·후 10초 클립 및 이벤트 로그 저장
- 날짜별 이벤트 조회·삭제와 브라우저 재생용 영상 변환
- TP/FP/FN/TN 기반 성능 평가 기록과 지표 계산

## 보존해야 할 핵심 동작

- ROI가 없거나 사람 또는 이동 차량이 없으면 위험으로 판정하지 않는다.
- 주정차로 판정된 차량은 위험 조건에서 제외하되 화면에는 표시한다.
- 영상 소스 이름은 ROI와 이벤트를 연결하는 식별자로 사용한다.
- 기본 실행 방식은 `streamlit run app.py`이다.

이 프로젝트는 교육용 캡스톤 성격을 유지하며, 실제 안전 설비를 대체하는 제품으로 간주하지 않는다.
