# 작업 기록 보관소

`docs/tasks/current.md`는 항상 현재 진행 중인 단일 작업만 담는다. 어떤 작업이 `State: verified`로 종료되고 새 작업을 시작할 때, Claude(Planner)는 종료된 `current.md`의 전체 내용을 이 폴더에 옮겨 보관한 뒤 `current.md`를 표준 빈 템플릿으로 초기화한다.

## 규칙

- 여기에는 **작업 기록(계획·구현 결과·테스트 결과·리뷰)만** 저장한다. 제품 코드나 실행 가능한 스크립트는 두지 않는다.
- 파일명 형식: `YYYY-MM-DD-짧은슬러그.md` (예: `2026-09-13-handoff-design.md`). 날짜는 해당 작업이 `verified`로 종료된 날짜를 쓴다.
- `docs/tasks/archive/` 디렉터리 신설 자체는 2026-09-13에 사용자 승인을 받아 진행했다. 이후 개별 작업을 `verified` 종료 시점에 이 폴더로 옮기는 것은 **매번 재승인받지 않고 자동으로 수행**한다 (`docs/RULES.md`의 "작업 상태(State)" 참고).
- 보관된 파일은 참고용 기록이며 수정하지 않는다. 새로운 결정이 필요하면 `current.md`에 새 작업으로 남긴다.
